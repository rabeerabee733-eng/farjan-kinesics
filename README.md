# فرجان الحركية — Kinesics Farjan V2

نسخة ويب تجريبية قابلة للنشر على GitHub Pages، مبنية كـ Static SPA بدون Backend.

## ما الذي تحتويه النسخة؟
- صفحة رئيسية عربية كاملة ومتجاوبة.
- إنشاء ملف طفل وحفظه محليًا في المتصفح.
- فحص أمان قبل اللعب.
- اختيار عالم الفريج.
- ثلاث ألعاب حركية: الحجلة الخليجية، جمع اللؤلؤ، رفع الشراع.
- تتبع وضعية الجسم عبر MediaPipe Pose داخل المتصفح.
- وضع محاكاة لاختبار الواجهة عند عدم توفر الكاميرا.
- نقاط وجولات ونتيجة جلسة.
- تقارير مبسطة وسجل جلسات محفوظ محليًا.
- لوحة أخصائي تجريبية لإعداد اللعبة وعدد الجولات ومدة الثبات.
- تصدير تقرير JSON من المتصفح.

## التشغيل محليًا
الكاميرا تحتاج سياقًا آمنًا. استخدم أحد الخيارات:

```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع `index.html` و `style.css` و `app.js`.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر فرع `main` والمجلد `/root`.
5. افتح رابط HTTPS الناتج وامنح إذن الكاميرا.

## الخصوصية
في هذه النسخة لا يوجد Backend، والفيديو لا يتم رفعه إلى خادم. بيانات الملف والجلسات تحفظ في `localStorage` على الجهاز نفسه.

## تنبيه مهم
المشروع في هذه المرحلة نموذج تقني/تجريبي وليس جهازًا طبيًا ولا أداة تشخيص أو علاج. يجب أن يعتمد أخصائي علاج طبيعي مؤهل قواعد الحركة، الحدود، الزوايا، والتدرج قبل أي استخدام علاجي فعلي.
