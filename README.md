# فرجان الحركية — النسخة النهائية

نسخة Static SPA جاهزة للنشر على GitHub Pages.

## الخصائص
- هوية قطرية وخليجية بأسلوب أنمي مضمّن داخل الواجهة.
- ألعاب حركية بتتبع MediaPipe Pose.
- قسم مستقل للنطق واللغة العربية باستخدام Web Speech API عند توفره.
- تعزيز صوتي عربي عبر Speech Synthesis.
- تقييم ذكي تجريبي للمهارات وتوصيات تحسين.
- تقارير تقدم وتقييم ولي الأمر.
- لوحة إعداد للأخصائي.
- تخزين محلي LocalStorage بدون قاعدة بيانات في هذه النسخة.

## نشر GitHub Pages
ارفع الملفات إلى جذر المستودع ثم Settings > Pages > Deploy from branch > main / root.

ملاحظة: الكاميرا والميكروفون يحتاجان HTTPS، وGitHub Pages يوفر HTTPS.
