# فرجان الحركية — V5

نسخة GitHub Pages مطوّرة من منصة **فرجان الحركية (Kinesics Farjan)** للأطفال.

## أبرز التحسينات
- شعار قطري/خليجي جديد مستوحى من المركب والبحر واللؤلؤ.
- شخصية أنمي 3D مضمّنة داخل الصفحة حتى لا تختفي عند النشر.
- واجهة أبسط على الكمبيوتر والهاتف.
- ركن نطق عربي من 6 مستويات متدرجة:
  1. الحروف الشفوية مع الفتحة والضمة والكسرة.
  2. الحروف الأمامية مع الحركات.
  3. أصوات تحتاج دقة أكبر.
  4. كلمات بسيطة مصورة.
  5. مفردات قطرية وخليجية مصورة.
  6. جمل قصيرة.
- شرح لمخرج كل حرف مع زر لسماع الشرح.
- نموذج صوتي عادي وبطيء.
- فحص للميكروفون قبل التدريب.
- تحسين التعرف على الصوت عبر عدة بدائل وعدة إعدادات عربية (قطرية/خليجية/عربية واضحة).
- تعزيز صوتي بعبارات قريبة من اللهجة الخليجية.
- فتح المستويات تدريجيًا عند تحقيق 65% في المستوى السابق.
- خيار تأكيد ولي الأمر عند ضعف التعرف الآلي.
- ألعاب حركية بتتبع MediaPipe وتقارير تقدم مبسطة.

## النشر على GitHub Pages
ارفع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، ثم:
`Settings → Pages → Deploy from a branch → main → /(root)`.
